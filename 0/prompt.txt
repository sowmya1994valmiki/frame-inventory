Accept all 6 review findings. Please fix them as follows:

1. MUST FIX — Stuck loading state
Make loading state controlled by the actual active/latest API request.
Do not set loading=true from debounce, filter, pagination, or other event handlers when an API request may not actually occur.
Ensure loading cannot remain stuck when the effective query/filter values do not change.

2. SHOULD FIX — Page correction loading race
Handle this together with #1.
If an out-of-range page is corrected and triggers another request, an older request must not set loading=false while the newer request is still running.
Only the active/latest request should control the final loading state.

3. SHOULD FIX — String filters request on every keystroke
Apply the same ~300 ms debounce pattern used by q search to the free-text filters:
- mediaType
- environment
- format
- region

Keep the status dropdown immediate because it is a single selection.
